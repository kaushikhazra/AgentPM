# AgentPM

AI-first personal project management system.

*Like Agent M from MIB, but for your projects.*

## Overview

AgentPM is designed for solo developers working with AI agents. The system is "AI-first" meaning it's designed to be operated primarily through AI assistants (Claude, Claude Code) via MCP, with a CLI as the secondary interface.

## Installation

```bash
pip install -e .
```

## Development

```bash
pip install -e ".[dev]"
pytest
```
